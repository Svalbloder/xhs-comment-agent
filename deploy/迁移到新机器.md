# 换一台主机怎么装

一句话：**代码在 GitHub，行为数据在本机**。只 clone 仓库装出来的，是"原厂默认"的新实例；
话术库、黑名单、登录态、已回复去重记录，都要从旧机器搬过去。

---

## 迁移前：先备份旧机器

在**旧机器**上，把整个运行目录打包：

```powershell
$src = "$env:USERPROFILE\.dsh\xhs-agent"
Copy-Item $src "$env:USERPROFILE\Desktop\xhs-agent-backup" -Recurse -Force
Compress-Archive "$env:USERPROFILE\Desktop\xhs-agent-backup" "$env:USERPROFILE\Desktop\xhs-agent-backup.zip" -Force
```

把这个 zip 拷到 U 盘 / 网盘。它包含账号登录态，**不要发给别人**。

---

## 第一步：新机器装代码

前置条件：

- Windows 10/11 x64
- DeepSeek Harness 桌面端**已安装且至少启动过一次**（插件要挂到它的配置里）

在**管理员 PowerShell** 里：

```powershell
git clone https://github.com/Svalbloder/xhs-comment-agent.git D:\xhs-comment-agent
cd D:\xhs-comment-agent
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\install.ps1
```

安装器会做这些事（幂等，可重复执行，写前备份、失败回滚）：

1. 下载 `xiaohongshu-mcp.exe`、`xiaohongshu-login.exe`（约 27MB，内置 3 个加速镜像，失败自动换）
2. 把插件注册进 DSH 的 `cordis.patch.yml`
3. 首次从 `scripts.default.json` 播种话术库

如果已经有 release 包，也可以下载 zip 解压后跑同一个 `install.ps1`。

---

## 第二步：搬运行数据（关键）

把备份里的文件覆盖到新机器的**同一路径**：

```
C:\Users\<用户名>\.dsh\xhs-agent\
```

必须带过来的文件：

| 文件 | 内容 | 不搬的后果 |
|---|---|---|
| `scripts.json` | 话术库：场景、触发词、话术、搜索词、黑名单、AI 经历提示 | 变回出厂话术，之前调的全没了 |
| `rules.json` | 标题预筛、评论过滤、字数、间隔、配额、两个安全开关 | 全部回落默认值 |
| `state.json` | 已回复评论去重、每篇笔记累计回复数、今日/本小时配额计数 | **可能重复回复同一批人**，配额从 0 重算 |
| `cookies.json` | 小红书登录态 | 要重新扫码登录 |
| `drafts.jsonl` | 回复清单历史 | 清单为空，之前的草稿没了 |
| `panel-token.txt` | 本地面板的访问令牌 | 面板访问方式要重配 |

可以不用带的：

- `scripts.json.bak-*` —— 自动备份，体积大
- `agent.log` / `boot.log` —— 日志，排查历史问题时才需要
- `login-qrcode.png` —— 过期的登录二维码

> 注意：`cookies.json` 绑定浏览器指纹，跨机器迁移**不一定还能用**。搬过去先看面板顶部是不是"已登录 · 你的昵称"，
> 不是的话重新扫码一次即可，其他数据不受影响。

---

## 第三步：重启并核对

1. 托盘图标 → 退出 → 重新打开 DSH
2. 右侧栏出现「小红书评论」标签；网页兜底地址 `http://127.0.0.1:18765/`
3. 面板顶部版本号应与仓库一致（例如 `v0.7.29`）；显示「旧页面 · 请 Ctrl+F5」就是没刷新

逐项核对：

- [ ] 话术库：场景数量、话术条数、搜索关键词、作者/评论黑名单都在
- [ ] 话术库：打开「纯模板」开关，按钮能切换（开 = 不调模型）
- [ ] 规则页：标题必须包含、每小时/每天上限、最小间隔、两个安全开关状态
- [ ] 登录态：显示"已登录 · 你的昵称"
- [ ] 跑一轮：能搜索、能出草稿、清单里有记录
- [ ] 去重：回复过的评论不应再出现在清单里

## 常见问题

**首次启动卡在"sidecar 未就绪"**
首次要下载 Chromium（约 425MB），慢网络下 10 分钟以上很正常。看日志
`C:\Users\<用户名>\.dsh\xhs-agent\agent.log`，失败就重跑 `install.ps1`。

**右侧栏没有「小红书评论」标签**
跑 `deploy/fix-dsh.ps1`（急救脚本），或确认 `cordis.patch.yml` 里有这个插件的一行配置。

**面板打不开 / 401**
`panel-token.txt` 里的令牌需要作为 URL 参数或请求头带上；换机后如果没搬这个文件，删除它会让插件重新生成。

**装完发现话术是默认的**
说明第二步没做或覆盖错了目录。检查 `%USERPROFILE%\.dsh\xhs-agent\scripts.json` 的修改时间。

---

## ⚠️ 两台机器不要同时跑

同一个小红书账号在两个浏览器里同时操作，很容易触发风控；而且两边 `state.json` 各记各的，
去重记录不互通，会出现**同一批评论被回复两遍**。

正确做法：确认新机器跑通后，在旧机器上执行

```powershell
cd D:\xhs-comment-agent
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\uninstall.ps1
```

再删除旧机器的 `%USERPROFILE%\.dsh\xhs-agent`（会丢登录态，确认不再用之后再做）。

---

## 不随仓库迁移的东西

| 项目 | 说明 |
|---|---|
| 小红书登录态 | 用 `cookies.json` 搬，或重新扫码 |
| Chromium 浏览器 | 首次运行自动下载，不随仓库 |
| 手机访问（Tailscale） | 需在新机器重装 Tailscale、重新配面板令牌与防火墙规则 |
| `~/.dsh/xhs-agent` 之外的任何东西 | 插件全部状态都在这个目录里 |
