# 客户机部署说明（Windows）

给**实施/交付同学**看的：在一台干净电脑上把这个产品装起来、跑通、交给客户。

---

## 一、前提

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，x64 |
| DSH | 桌面端已安装，并且**至少启动过一次**（要它生成 `%USERPROFILE%\.dsh\profiles\...`） |
| 账号 | 一个能正常登录的小红书账号（建议先实名，新号容易被要求验证） |
| 网络 | 能访问 GitHub 镜像（安装器默认走 `ghfast.top`，失败自动换源） |
| 权限 | 安装需要管理员（仅用于 Defender 排除；不加也能装，见排错表） |

> 不需要装 Node、Python、Docker。插件跑在 DSH 宿主进程里。

## 三、安装

在**管理员** PowerShell 里：

```powershell
cd <解压目录>\xhs-comment-agent
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\install.ps1
```

安装器做五件事：

1. 复制插件到 `%USERPROFILE%\.dsh\plugins\xhs-comment-agent`（`src\` + `package.json`）
2. 下载 `xiaohongshu-mcp.exe` / `xiaohongshu-login.exe` 到 `%USERPROFILE%\.dsh\runtimes`
3. 把插件软链进 profile 的 `node_modules` 并登记依赖（**客户端右侧栏需要"包"形态**）
4. 在 profile 的 `cordis.patch.yml` 登记插件行
5. 添加 Defender 两个排除目录

常用参数：

| 参数 | 用途 |
|---|---|
| `-Preview` | 只检查 + 打印，不写任何文件。**第一次装建议先跑** |
| `-SkipDownload` | 二进制已就位（离线交付） |
| `-SkipDefender` | 不动杀软设置 |
| `-RunLogin` | 装完直接弹扫码窗口 |

### 安装器写文件的硬性约束（重要）

**所有文本文件都以 UTF-8 无 BOM 写入。**

DSH 用 `JSON.parse` 读 `profiles/<name>/package.json`，文件开头带 `\uFEFF` 会让宿主在启动阶段直接崩：

```
SyntaxError: Unexpected token '\uFEFF' ... at readProfileManifest
→ DesktopHostFatalError（窗口打不开）
```

安装器为此做了四道保险：

1. 写文件一律走 `[IO.File]::WriteAllText(..., UTF8Encoding($false))`，
   绝不用 `Set-Content -Encoding utf8`（PowerShell 5.1 会写 BOM）；
2. 写完 `package.json` 立刻用 `ConvertFrom-Json` 再解析一次，失败回滚备份并中止；
3. 写完 `cordis.patch.yml` 校验"无 BOM + 含插件行"，失败回滚；
4. 安装开始时体检：历史文件若带 BOM，先备份再清除。

## 四、首次登录（只做一次）

```powershell
cd "$env:USERPROFILE\.dsh\xhs-agent"
& "$env:USERPROFILE\.dsh\runtimes\xiaohongshu-login.exe"
```

会弹一个 Chromium 窗口，用手机小红书扫码。成功后 cookies 落在
`%USERPROFILE%\.dsh\xhs-agent\cookies.json`。

> **必须在这个目录下运行登录**。xiaohongshu-mcp 从"当前工作目录"读 cookies，
> 换目录启动服务，登录态会直接消失（实测 `is_logged_in: false`）。

> 同一账号**不要**在多个网页端同时登录，否则会把这边踢下线。

## 五、重启 DSH

托盘图标右键 → 退出（不是关窗口），再打开。

插件只在 DSH 启动时装配，不重启不生效（右侧栏的标签也是）。

## 六、验证清单

| # | 动作 | 期望 |
|---|---|---|
| 1 | 看 DSH **右侧栏** | 出现「小红书评论」标签（💬） |
| 2 | 点开标签 | 状态条：服务在线、已登录（显示昵称）、今日 0/20 |

| 4 | 点「导入清单」→ 选客户 xlsx | 显示读了几个字段；缺必填会标出来 |
| 5 | 对话里让 Agent 搜关键词 | 返回笔记列表（带 feedId / xsecToken） |
| 6 | 让它抓某篇笔记评论 | 返回一级/二级评论候选 |
| 7 | 让它"做成草稿" | 右侧栏「待审草稿」出现条目 |
| 8 | 干跑状态下点「发送这条」 | 被拒绝（`dry_run_on`）——这是对的 |
| 9 | 关干跑 → 保存 → 发送一条 | 小红书网页上能看到回复挂在目标评论下 |

网页兜底：`http://127.0.0.1:18765/`（同一套功能，也是客户端 UI 的数据源）。

## 七、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| **DSH 窗口打不开**，日志 `Unexpected token '\uFEFF'` | 某个 profile 的 `package.json` 带 BOM | 跑 `deploy\fix-dsh.ps1`，或手动去 BOM 后重开 |
| DSH 打不开，但没有 BOM | 插件行导致 | 跑 `deploy\uninstall.ps1` 摘掉插件行再启动 |
| 右侧栏没有「小红书评论」 | 客户端半侧没装配 | 确认 `bundle\package.json` 存在且 `dsh.client` 段完整；重启 DSH；仍无则看开发者工具 Console 里 `[xhs-agent]` 警告 |
| 右侧栏有标签但一直"连接面板中…" | 本地面板没起来 / 端口被占 / 缺 CORS | `Get-NetTCPConnection -LocalPort 18765`；确认 `panel.js` 含 `access-control-allow-origin` |
| 面板「服务离线」 | 18060 被占，或 exe 被删 | 查端口；确认 `~/.dsh/runtimes` 两个 exe 在 |
| 登录窗口一开就闪退，日志 `leakless.exe ... virus` | Defender 把 rod 的进程守护当病毒 | `Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\xiaohongshu-mcp"` 及 `%TEMP%\leakless-amd64-*` 所在目录 |
| 登录成功但很快未登录 | 服务工作目录不是 `~/.dsh/xhs-agent` | 不要手动在别处起服务；插件 `cwd` 已钉死 |
| 搜索一直 0 条 | 登录态失效 / 关键词太窄 / 筛选太严 | 先看登录状态；放宽 `min_liked`、`title_must_any` |
| 评论 0 个候选 | `must_any` 太严 | 暂时清空 `must_any`，干跑看全量再收紧 |
| 发送被拒 `daily_quota`/`cooldown`/`already_sent` | 风控生效 | 正常行为，等或用别的评论 |
| 发送被拒 `dry_run_on` | 干跑还开着 | 取消勾选「干跑」并保存 |
| 报 `0xC0000142` | DSH 自己的 pwsh 沙箱问题，**与本插件无关** | 插件在宿主进程内 spawn，不走沙箱 |

## 八、升级

重跑安装器即可（幂等）：覆盖插件代码、重写同一行配置、重新备份。

- 规则、草稿、去重记录在 `~/.dsh/xhs-agent`，升级不动；
- **客户端 UI 的代码要重启 DSH 才换**；面板里的规则/配额是即时生效的。

---

## 九、卸载

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\uninstall.ps1          # 保留数据
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\uninstall.ps1 -Purge   # 连数据一起删
```

卸载后重启 DSH。

急救脚本 `fix-dsh.ps1` 做三件事：清 BOM → 校验 manifest（坏就用备份恢复）→ 重新拉起 DSH。

---

## 十、安全与合规

- 面板与客户端都只访问 `127.0.0.1`；**面板没有鉴权，不要做端口转发、不要暴露公网**。
- `cookies.json` 是明文登录态，等同账号密码，不要打包发给别人。
- 自动回复属于平台敏感行为：默认干跑、有小时/天配额、有去重和熔断，**不要为了跑量关掉**。
- 建议先在自己笔记下试回复，再放到别人笔记；回复内容不要导流、不要报价。
